# Rain — 磨砂玻璃工作流工作台

一个用纯 HTML / CSS / 原生 JS 做的桌面应用界面（不是网页），四个视图：Dashboard、Runs、Approvals、Builder（可拖拽的流程画布）。

## 打开方式

直接双击 `index.html` 即可，无需构建、无需联网。字体 `fonts/Inter-Variable.woff2` 是本地文件。

```
glass/
  index.html   外壳：窗口、标题栏、侧栏、内容区
  glass.css    全部样式
  data.js      数据（window.RAIN）
  app.js       渲染与交互
  fonts/       Inter 可变字体
```

## 关于"透明"

整份样式里只有一处有颜色：**壁纸层**（`css` 里的 `.field`，一条品红→酒红的渐变，左上角一团白光）。除此之外，没有任何面板写过自己的填充色。

- 左侧栏是一层淡玻璃：只做了 `blur + brightness(0.62)`，所以它透出来的是壁纸本身，越靠上越亮、越靠下越暗。
- 右侧内容区是烟熏玻璃：同一张壁纸，`blur + brightness(0.2) + saturate(0.2)`，压暗后只剩一层酒红色的影子。左右深浅不同，但来自同一片背景。
- 卡片、项目组、胶囊按钮上的白，全是 6%–12% 的白色透明度——不是配色，是玻璃的厚度。
- 唯一的彩色是状态色（成功 / 失败 / 待处理）。

想换成别的壁纸，只改 `.field` 里的那条渐变就行，整个界面的色调会自己跟着变——这正是这套做法的意义。

**标题栏右上角有一个 `Wallpaper` 按钮**，点一下会把壁纸换成一片没有色相的中性灰（只剩明暗），这样可以直接验证：界面本身一点颜色都没有，所有的红都是后面那层透出来的。再点一下换回来。

如果浏览器不支持 `backdrop-filter`（老版 Firefox 等），会退化成一层纯色底——结构不会坏，只是失去磨砂质感。Chrome / Edge / Safari 均正常。

## 数据是对得上的

`data.js` 里每个工作流的运行次数之和 = 286，成功 284、失败 2，成功率 99.3%；手动节省时间由 `每次运行节省分钟 × 运行次数` 算出（822 分钟 = 13 h 42 m，平均 2.9 分钟/次）。`decorate()` 里用 `console.assert` 守着这些和，改数据时能立刻发现对不上。

## 交互

- 侧栏四个入口切换视图；项目树可展开/收起，点工作流进入画布。
- 画布里的节点可以拖动，连线是 SVG 贝塞尔曲线，缩放 100% / ±。
- `/` 聚焦搜索，`Esc` 关掉抽屉或取消选中，画布内 `Ctrl/Cmd + Enter` 执行工作流。
- 窗口宽度小于 1080px 时侧栏收窄，小于 760px 变成抽屉（左上角菜单按钮打开）。
